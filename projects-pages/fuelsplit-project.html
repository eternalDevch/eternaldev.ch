Fuelsplit

Development

Overview

A pre-session fuel strategy tool for endurance racing. Built in Python, the calculator takes race duration, average lap time, pit stop time, safety lap margin and fuel consumption per lap as manual inputs. It outputs total laps driven, optimal pit stop count and timing, and the exact fuel load needed per stint giving the driver a complete strategy picture before lights out.

Mission

Eliminate guesswork at the pit wall. Endurance races are lost on fuel miscalculation running dry or carrying dead weight. This tool turns five inputs into a full stint strategy, so every decision going into a race is backed by numbers.

Stack

Approach

Pure logic, no decoration. Input goes in, strategy comes out. No UI layer yet, the calculation engine is the product. Direct in-game data integration is planned, pulling live telemetry straight from LMU via rFactor 2 shared memory to replace manual input entirely.
